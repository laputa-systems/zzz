# AGENTS.md

zzz is a static Linux suspend and hibernate command written in one Zig file.

- Use Zig 0.17.1, the version in `.zig-version`.
- Run `make lint` to compile-check `zzz.zig`.
- Run `make test` on Linux for unit tests and the `--help` contract.
- Do not run `zig fmt`. The fleet bans formatters.
